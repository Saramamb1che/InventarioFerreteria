# InventarioFerreteria

Sistema de inventario para Ferretería Los Robles, desarrollado como práctica de
Programación de Aplicaciones de Escritorio.

## Tecnologías

- Visual Basic .NET y Windows Forms sobre .NET 10.
- MariaDB (versión instalada para esta práctica: 12.3).
- MySqlConnector 2.4.0 (pendiente de agregar al proyecto).
- Git y GitHub.

## Organización

- `database/`: scripts SQL numerados, ejecutados en orden.
- `docs/`: acuerdos de trabajo y documentación.
- `src/`: proyecto de la aplicación de escritorio.

## Estado
